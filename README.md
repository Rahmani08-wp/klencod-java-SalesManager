# تسيير المبيعات (Android / Java)

مشروع Android Studio كامل بلغة Java.

## الصفحات
- **لوحة التحكم**: عدد السلع، إجمالي المخزن، مبيعات اليوم، آخر رصيد افتتاحي + أزرار التنقل.
- **الكتالوج**: إضافة سلعة بصورة واسم (تعديل / حذف بالضغط على السلعة).
- **المخزن**: كل سلعة مسجلة في الكتالوج تظهر هنا تلقائيا (كمية 0). بحث + تعديل الكمية والسعر.
- **المبيعات**: تظهر فقط السلع المتوفرة في المخزن (الكمية > 0). البيع ينقص المخزن تلقائيا.
- **الرصيد الافتتاحي**: إدخال مبلغ يدويا لكل تاريخ، ويحفظ حسب التاريخ مع سجل بالأرصدة.

## المواصفات
- applicationId: `com.salesmanager.app`
- minSdk 24 / compileSdk 34
- Android Gradle Plugin 8.2.2 + Gradle 8.2 (يتطلب JDK 17)
- قاعدة بيانات SQLite محلية (بدون مكتبات خارجية للصور أو قاعدة البيانات)

## التشغيل
1. فك الضغط ثم افتح المجلد `SalesManager` في Android Studio.
2. انتظر Gradle Sync (يحتاج اتصال إنترنت أول مرة).
3. Run ▶ على هاتف أو محاكي.
